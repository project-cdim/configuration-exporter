# Changelog 0.2

## [0.2.1](https://github.com/project-cdim/configuration-exporter/compare/v0.2.0...v0.2.1) - 2026-10-09

The changes from v0.2.0 are as follows:

### Features

- Added support for configuring the log tag and output type through logger configuration files (`configs/logger_settings_app.yaml`, `configs/logger_settings_trail.yaml`).

### Breaking Changes

- Updated required Go version from 1.24+ to 1.26+.
